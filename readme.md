# 🧠 Learning Philosophy

I believe that becoming a good programmer is not about remembering syntax—it's about understanding how to solve problems.

For every topic and coding problem, my approach is:

1. Understand the concept.
2. Analyse the problem carefully.
3. Identify the underlying pattern.
4. Design the algorithm.
5. Implement the solution in Python.
6. Verify correctness with different test cases.
7. Analyse time and space complexity.
8. Improve the solution whenever possible.

The focus is always on **learning the thought process behind the solution**.
